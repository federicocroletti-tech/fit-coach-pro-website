# Fit Coach Pro Website

Sito web moderno e professionale per un personal trainer che lavora in palestra, all'aperto, privatamente su appuntamento e in collaborazione con palestre o piccoli gruppi.

## Brand demo

- Brand: **Fit Coach Pro**
- Personal trainer: **Marco Vitali**
- Claim: **Allenati meglio. Vivi più forte.**

## Pagine

- `/` - Home
- `/prenota` - Form di contatto e prenotazione
- `/privacy-cookie` - Privacy Policy e Cookie Policy dimostrative

## Funzionalità

- Landing page responsive orientata alla conversione
- Servizi, metodo di lavoro, testimonianze e call to action
- Form di prenotazione con Reactive Forms e privacy obbligatoria
- Cookie banner con consenso granulare e preferenze in `localStorage`
- SEO base per pagina, canonical, Open Graph e dati strutturati
- `sitemap.xml` e `robots.txt`

## GDPR e cookie

I testi privacy e cookie sono modelli dimostrativi e devono essere validati da un consulente legale prima della pubblicazione definitiva. Il progetto non carica analytics reali prima del consenso: il consenso analytics emette solo un evento locale dimostrativo.

## Installazione

```bash
git clone https://github.com/federicocroletti-tech/fit-coach-pro-website.git
cd fit-coach-pro-website
npm install
npm start
```

## Build

```bash
npm run build
```
